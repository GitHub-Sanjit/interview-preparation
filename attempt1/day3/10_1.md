// Maximum sum of subarray of size k

## `maxSum(nums, k)` — Sliding Window Maximum Sum

This function finds the **maximum sum of any contiguous subarray of size `k`** using the **Sliding Window** technique.

---

### Core Idea

Instead of recalculating the sum of every window from scratch, it **slides** a window of size `k` across the array — adding the new element on the right and dropping the old element on the left.

---

### Step-by-Step with Example

**Input:** `nums = [2, 1, 5, 1, 3, 2]`, `k = 3`

| Step | `i` | `nums[i]` | `sum` (after add) | `i >= k-1`? | `max` | `sum` (after drop) | Window |
|------|-----|-----------|-------------------|-------------|-------|--------------------|--------|
| 1 | 0 | 2 | 2 | ❌ | 0 | — | `[2]` |
| 2 | 1 | 1 | 3 | ❌ | 0 | — | `[2,1]` |
| 3 | 2 | 5 | 8 | ✅ | 8 | 8 - 2 = **6** | `[2,1,5]` |
| 4 | 3 | 1 | 7 | ✅ | 8 | 7 - 1 = **6** | `[1,5,1]` |
| 5 | 4 | 3 | 9 | ✅ | 9 | 9 - 5 = **4** | `[5,1,3]` |
| 6 | 5 | 2 | 6 | ✅ | 9 | 6 - 1 = **5** | `[1,3,2]` |

**Output:** `9`

---

### Code Breakdown

```js
function maxSum(nums, k) {
  let sum = 0, max = 0;
```
> Initialize `sum` (current window total) and `max` (best sum found).

```js
  for (let i = 0; i < nums.length; i++) {
    sum += nums[i];          // ➕ Grow window by adding right element
```
> Always add the current element to the window.

```js
    if (i >= k - 1) {        // ✅ Window has reached size k
      max = Math.max(max, sum);       // 🏆 Update max if current window is better
      sum -= nums[i - k + 1];        // ➖ Shrink window by dropping left element
    }
```
> Once the window is full (size = `k`), compare with max, then slide forward by removing the leftmost element.

```js
  }
  return max;                // 🎯 Return the best sum found
}
```

---

### Why `i - k + 1`?

This is the **index of the leftmost element** in the current window.

- At `i = 2`, `k = 3` → left index = `2 - 3 + 1 = 0` → drops `nums[0]` ✅
- At `i = 4`, `k = 3` → left index = `4 - 3 + 1 = 2` → drops `nums[2]` ✅
